# CHG-006: LWSバージョンの正本をパッケージ管理下へ移行

Status: SHIPPED
Reason: `lwsctl`に埋め込まれた版情報とComposeへ未exportの設定により、更新後も古いイメージタグを参照していたため。
Change: `/usr/share/lws/version`をLWS版の正本とし、パッケージへインストーラーも配置する。`lwsctl update`はパッケージ更新後に新しい版情報でComposeを再起動する。
FilesChanged: scripts/lwsctl, scripts/package.sh, packaging/lws.spec.in, scripts/test.sh
Verification: `mise run lint`、`mise run test`、`mise run package --version 0.1.2`
Related: BUG-004, CHG-005
CurrentValue: current
ValidityScope: LWSの更新とパッケージ配布
