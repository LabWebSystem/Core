# CHG-090: Operation path parameterのUUID契約をOpenAPIへ追加する

Status: SHIPPED
Area: Backend HTTP API
Reason: `/operations/{operation}`の`operation`に指定できる値がOpenAPI UIだけでは分からなかったため。
Change: Operation IDをUUID v4形式の共通OpenAPI schemaとして定義し、説明・例・patternを追加した。Operation resource nameも`operations/<UUID>`形式として定義した。custom method suffixのSSE routeは、OpenAPI検証前に`:watch`を除去して同じUUID契約で検証する。
FilesChanged: backend/openapi.yaml, backend/openapi.gen.go, backend/openapi_server.go, backend/http.go, backend/backend_test.go, backend/phase5_test.go
Verification: `go test ./backend/...`、`mise run generate-backend`
Related: ADR-003
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Operation APIのpath parameterとresource name
