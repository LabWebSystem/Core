# CHG-081: Backend内のDocker Composeをv5.5.0へ固定する

Status: SHIPPED
Reason: Alpineの`docker-cli-compose`が提供するCompose v2.36.2では、開発用Compose Watchの`initial_sync`を含む新しいCompose仕様を検証できなかったため。
Change: Backend imageでは`docker-cli-compose` APKを使用せず、Docker公式Compose v5.5.0 pluginをamd64/arm64別チェックサム検証付きで導入する。Alpine、Docker CLI、git、eudevは維持する。
FilesChanged: backend/Dockerfile
Verification: `docker build --file backend/Dockerfile .`、生成imageで`docker compose version`がv5.5.0、Compose plugin存在確認
Related: ADR-006, CHG-080
CurrentValue: current
ValidityScope: Backend imageのDocker Compose plugin
