# CHG-012: GitHub ActionsのCIとリリースを段階並列化する

Status: SHIPPED
Reason: CIとLWSリリースが単一ジョブ内で直列実行され、独立した静的検査、テスト、パッケージ生成、およびBackendとDashboardのイメージ公開を並列に実行できなかった。
Change: CIはlint、test、packageを独立ジョブにする。LWSリリースは品質検証後にBackendとDashboardのイメージを並列公開し、パッケージartifactと両イメージ公開を待ってGitHub Releaseを作成する。SDKリリースはテストとビルドを並列にし、ビルドartifactを公開ジョブへ渡す。
FilesChanged: .github/workflows/ci.yml, .github/workflows/release-lws.yml, .github/workflows/release-sdk.yml
Verification: mise run lint, mise run test, mise run package
Related: ADR-001, CHG-010, CHG-011
CurrentValue: current
ValidityScope: GitHub ActionsのCIおよびCore・SDKリリース
