# CHG-010: バージョン設定と公開操作を分離する

Status: SHIPPED
Reason: `deploy`へ複数コンポーネントのバージョン指定を集める方式では、何を公開する操作なのかが分かりにくく、SDKとCoreの独立したバージョン管理も不明瞭だった。
Change: `mise run version`で各コンポーネントの現在版を一覧表示し、`mise run version <core|sdk> x.y.z`で各コンポーネントの正本を更新する。`mise run release <core|sdk|all>...`は指定コンポーネントの現在版を公開する。Core版は`version/core`、SDK版は`sdk/package.json`を正本とする。公開Workflowはタグと正本の一致を検証する。
FilesChanged: version/core, scripts/version.sh, scripts/release.sh, scripts/package.sh, mise.toml, .github/workflows/release-lws.yml, .github/workflows/release-sdk.yml, README.md, scripts/test.sh
Verification: `mise run lint`、`mise run test`、`mise run package`、`memadr check`、`memadr index`
Related: ADR-001, CHG-005, CHG-009
CurrentValue: current
ValidityScope: CoreとSDKのバージョン管理および公開操作
