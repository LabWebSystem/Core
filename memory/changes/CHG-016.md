# CHG-016: updateで停止状態を維持する

Status: SHIPPED
Reason: 停止中のLWSを更新すると、利用者の意図に反してコンテナが起動していた。
Change: `update`はパッケージ更新前に稼働serviceを確認し、再実行後にその結果を引き継ぐ。停止中ではパッケージとimageを更新するだけで終了し、起動中だけ再起動する。
