# CHG-003: 初回起動時にベースドメインをComposeへ渡す

Status: SHIPPED
Reason: 初回`lwsctl start`で設定を保存しても、Composeが必要とする`LWS_BASE_DOMAIN`がプロセス環境に存在しなかったため。
Change: `write_config`で`LWS_BASE_DOMAIN`をexportし、Compose実行時の環境を検証する回帰テストを追加した。
FilesChanged: scripts/lwsctl, scripts/test.sh
Verification: `mise run lint`、`mise run test`、`mise run package --version 0.1.0`
Related: BUG-002, ADR-001
CurrentValue: current
ValidityScope: LWSの初回起動とベースドメイン変更
