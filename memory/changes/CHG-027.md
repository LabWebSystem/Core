# CHG-027: OpenAPI生成serverをHTTP入口へ接続する

Status: SHIPPED
Reason: OpenAPI生成物が存在しても、実際のHTTP入口が手書きrouteのままでは契約と実装の乖離を検出できないため。
Change: 生成ServerInterfaceを実装するadapterを追加し、通常routeを生成wrapper経由で登録した。Go標準ServeMuxがwildcard直後のcustom methodを受け付けないため、custom methodとSSE suffix routeだけは既存dispatcherへ明示的に委譲する。OpenAPI request schema、生成spec読み込み、生成routeのHTTPテストを追加した。
FilesChanged: backend/openapi.yaml, backend/openapi.gen.go, backend/openapi_server.go, backend/http.go, backend/backend_test.go
Verification: go test ./backend/..., mise run test, mise run test backend-http, mise run lint, mise run check-openapi, docker compose -f infrastructure/compose.yaml config
Related: ADR-003, CHG-024
CurrentValue: current
ValidityScope: OpenAPI生成・Backend HTTP基盤
