# CHG-066: Dashboardの公開URLとOperation進行表示を修正する

Status: SHIPPED
Reason: 開発用Dashboardでは公開URLのportが失われてアプリへ接続できず、BackendのカスタムSSEイベントもDashboardが受信していなかったため、登録中の進行状況を確認できなかった。
Change: 公開URLに現在のOrigin portを維持し、DashboardがカスタムSSEイベントを状態として処理して終端時に購読を閉じるよう修正した。Backendも終端イベントの送信後にSSEを正常終了する。Backendはリポジトリ取得、定義検証、Compose起動、公開設定更新の進行をSSEで通知する。
FilesChanged: dashboard/src/App.tsx, dashboard/src/api/client.ts, backend/operations.go, backend/worker.go, backend/runtime.go
Verification: Dashboard API client test、Backend test、Dashboard buildを実行する。
Related: ADR-004, ADR-012, CHG-064, CHG-065
CurrentValue: current
ValidityScope: Dashboardのアプリ操作とSSE進行表示
