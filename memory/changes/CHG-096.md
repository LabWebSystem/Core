# CHG-096: mDNS公開ホスト名を単一ラベル形式へ変更する

Status: SHIPPED
Area: Backend / Dashboard / CLI / Infrastructure / Packaging / Documentation
Reason: WindowsのmDNS resolverが3ラベル以上の名前を解決できない問題に対応するため。
Change: アプリ、Dashboard、APIのホスト名をベースドメイン末尾のラベルより前とハイフン連結する形式へ変更した。APIとSQLiteのアプリ名項目を`appName` / `app_name`へ変更し、既存SQLiteの値を保持する列名migrationを追加した。ベースドメインを含め生成DNSラベルが63文字を超える場合は拒否する。DashboardのURL表示、Avahi hosts、Caddy route、Backend Host/Origin、Compose healthcheck、開発環境を新形式へ揃えた。
FilesChanged: .dockerignore, backend/Dockerfile, backend/derived.go, backend/derived_manager.go, backend/validate.go, backend/migrations/012_app_names.sql, backend/openapi.yaml, backend/openapi.gen.go, backend/http.go, backend/applications.go, backend/runtime.go, backend/cmd/lws-backend/main.go, cmd/lwsctl/compose.go, internal/hostname/hostname.go, dashboard/src/App.tsx, dashboard/src/api/schema.ts, infrastructure/compose.yaml, infrastructure/compose.dashboard-dev.yaml, scripts/test-infrastructure.sh, scripts/verify.sh, qa/resources/api.resource, qa/resources/lifecycle.resource, README.md, CHANGELOG.md, docs/Backend仕様書.md, docs/Infrastructure仕様書.md, docs/LabWebSystem設計概要.md, docs/LWS v0.1.14利用マニュアル.md
Verification: `go test ./backend/... ./cmd/lwsctl/...`、`mise run verify fast`、`mise run package`、`mise run check-openapi`、`mise run test`、`mise run lint`、Robot Frameworkのlifecycle dry-runと`mise run qa-lifecycle`を実施。Release検証でRobot Process引数順序の不備、隔離Compose fixtureのAvahi digest参照不備、Backend Docker build contextから`internal/hostname`が欠落する不備を検出して修正した。ローカルlifecycle suite setupは修正後に通過し、必須ホストポート使用中の安全なskipを確認。Docker build context allowlist修正後にBackend image buildとGitHub Release検証を再確認する。
Related: ADR-018, SUP-003
CurrentValue: current
FutureRelevance: reusable
ValidityScope: LWSアプリ、Dashboard、APIのmDNS公開名とAPIアプリ名契約
