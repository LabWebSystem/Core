# CHG-001: Ubuntu系とAlmaLinux系のインストーラー分岐

Status: SHIPPED
Reason: AlmaLinux 9にはapt-getがなく、OS判定前にDEBを選択していたためインストールに失敗していました。
Change: `/etc/os-release`からUbuntu系とAlmaLinux系を判定し、Ubuntu系ではDEBとAPT、AlmaLinux系ではRPMとDNFだけを選択するようにしました。対応外OSとパッケージマネージャー不足も変更前にエラーにします。
FilesChanged: scripts/install.sh, README.md
Verification: `mise run lint`、`mise run test`、`mise run package --version 0.1.0`、`git diff --check`
Related: ADR-001
CurrentValue: current
ValidityScope: Ubuntu系およびAlmaLinux系のLWSインストール
