# CHG-044: 旧設定ファイルの権限をパッケージ更新時に移行する

Status: SHIPPED
Reason: 旧版が作成した`/etc/lws/config.env`を新しい`lwsctl`が権限不正として拒否し、パッケージ更新後の再実行に失敗する場合があったため。
Change: Debianの`preinst`とRPMの`%pre`で、既存の設定ファイルがある場合に権限を`0600`へ補正する。通常の`lwsctl`読込時に不正な権限を拒否する契約は維持する。
FilesChanged: packaging/lws.preinst, packaging/lws.spec.in, scripts/package.sh, scripts/test.sh
Verification: `mise run test cli`, `mise run test installer`, `mise run lint`, `mise run package`
Related: CHG-043
CurrentValue: current
ValidityScope: LWSパッケージ更新時の既存設定移行
