# CHG-070: Dashboardのアプリ運用ログ面を構造化する

Status: SHIPPED
Reason: 登録画面へ切り替えられず、右ペインが端末風のアプリログだけを表示していたため、登録・同期などのOperation出力と複数サービスの状態を追跡しにくかった。
Change: 登録フォーム表示状態を選択アプリから分離した。希望状態表示を削除し、右ペインをtask/application/relatedのログタブへ置換した。ログは時刻、level、タスク・service・component、本文を構造化行として表示し、アプリログはBackendのservice filterを使うプルダウンで絞り込む。
FilesChanged: dashboard/src/App.tsx, dashboard/src/api/client.ts, dashboard/src/styles.css, dashboard/src/App.test.tsx
Verification: npm --prefix dashboard run lint、npm --prefix dashboard test -- --run、Impeccable detector
Related: ADR-004, ADR-013, CHG-067, CHG-069
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Dashboard登録画面、アプリ運用ログ、サービス絞り込み
