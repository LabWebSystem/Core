# CHG-074: ログのseverity判定と条件付き表示を整理する

Status: SHIPPED
Reason: 正常なstderrがerror表示され、複数行JSONと大量の保存ログがDashboardの可読性を損ねていたため。
Change: 外部コマンドは失敗時だけerrorログを追加し、`[error]`等のseverity markerを解析するようにした。ログ保存時に1行へ正規化し、DashboardはJSONをコンパクトな構造化ブロックで表示する。ログ取得へ件数・開始日時・終了日時を指定できるUIを追加し、既存のcursor／SSE再開条件も利用する。
