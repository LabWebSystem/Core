# CHG-068: Operation待機列とSQLite書込み待機を追加する

Status: SHIPPED
Reason: 同一アプリへの異なるOperationが409で拒否され、RuntimeMonitorのログ保存とOperation状態更新が同時書込み時に`SQLITE_BUSY`で失敗し得た。
Change: 同一app-idのOperationを永続化された`QUEUED`状態でFIFO実行し、同一内容の再送は既存の未完了Operationへ収束させた。異なるapp-idは従来どおり最大2件並列とする。SQLite接続ごとにWAL、foreign key、5秒の`busy_timeout`を適用し、短い書込み競合を待機する。
FilesChanged: backend/db.go, backend/operations.go, backend/worker.go, backend/applications.go, backend/backend_test.go
Verification: go test ./backend、npm --prefix dashboard test -- --run、npm --prefix dashboard run lint
Related: ADR-004, ADR-006, ADR-013, CHG-067
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Backend Operation待機、再送、SQLite書込み競合
