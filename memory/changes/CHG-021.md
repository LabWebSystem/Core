# CHG-021: Composeの必須環境変数展開をBackend検証へ移す

Status: SHIPPED
Reason: Composeの変数展開構文へ利用者向けエラー文を埋め込まず、Composeの責務とBackendの設定検証を分離するため。
Change: `LWS_BASE_DOMAIN`未設定時はComposeへ空値を渡し、Backend起動時のベースドメイン検証で拒否するよう変更した。
FilesChanged: infrastructure/compose.yaml, backend/validate.go, backend/cmd/lws-backend/main.go
Verification: docker compose config, go test ./..., mise run lint
Related: ADR-002, CHG-019
CurrentValue: current
ValidityScope: LWS_BASE_DOMAINのCompose・Backend境界
