# CHG-078: Compose検証JSONを一行でOperationログへ記録する

Status: SHIPPED
Reason: `docker compose config --format json` の整形済み出力をストリーミングで行ごとに記録していたため、Compose検証ログがJSON断片として分割表示された。
Change: Compose検証は出力を一度回収し、検証に使う元のJSONは変更せず、OperationログだけをJSON Compactした一行として記録する。JSON以外の出力は従来どおり一件のログとして記録する。
FilesChanged: backend/source.go, backend/runtime.go, backend/backend_test.go
Verification: `go test ./backend/...`、`mise run test backend`、`mise run lint`
Related: ADR-013, CHG-069, CHG-071
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Compose検証のOperationログ出力
