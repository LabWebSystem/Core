# CHG-101: リリースWorkflowから事前品質検証を分離する

Status: SHIPPED
Area: CI / Release
Reason: リリース公開処理と品質検証が同じWorkflowに結合され、検証後に公開する運用が曖昧だった。
Change: `mise run verify full`をリリース前の品質確認手順とし、同一commitを対象にCoreまたはSDKの公開コマンドを実行する。LWSリリースWorkflowをタグ起動の公開専用にし、SDKリリースWorkflowからテストを外して公開用buildとnpm publishを同じjobで実行する。README、品質ゲート仕様、ADR-019を運用に合わせる。
FilesChanged: .github/workflows/release-lws.yml, .github/workflows/release-sdk.yml, README.md, CHANGELOG.md, version/core, docs/品質ゲート統合実装計画.md, docs/機能テストルール.md, scripts/test-quality-architecture.sh, memory/decisions/ADR-019.md
Verification: `mise run test architecture`、`mise run test release`、Workflow YAML構文検査、`git diff --check`。
Related: ADR-019, CHG-098
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Core・SDKの事前検証と公開Workflow
