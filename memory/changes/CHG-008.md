# CHG-008: lwsctlのGo実装を責務ごとに分割する

Status: SHIPPED
Reason: `main.go`にCLI起動、引数解析、設定管理、Docker Compose実行、対話入力、ライフサイクル操作が集中し、変更時の影響範囲を把握しにくかったため。
Change: CLI起動を`main.go`、パス解決を`paths.go`、設定とLWSバージョン読込を`config.go`、Compose実行を`compose.go`、対話入力を`prompt.go`、ヘルプを`help.go`、コマンド操作を`commands.go`へ分割する。LWS実行バージョンは引き続きパッケージ管理下のversionファイルを正本とする。
FilesChanged: cmd/lwsctl/main.go, cmd/lwsctl/paths.go, cmd/lwsctl/config.go, cmd/lwsctl/compose.go, cmd/lwsctl/prompt.go, cmd/lwsctl/help.go, cmd/lwsctl/commands.go, scripts/lint.sh
Verification: `mise run lint`、`mise run test`、`mise run package`
