# CHG-080: 登録アプリのhost bind mount変換を廃止する

Status: SHIPPED
Reason: Backend containerからDocker daemonへ渡すhost pathは、開発環境と本番環境で一致せず、bind-backed Volumeへの変換はアプリsourceと実行環境の責務を複雑にしていたため。
Change: 登録アプリのComposeではhost bind mountと匿名Volumeをsource検証時に拒否し、bind mountをLWS所有Volumeへ変換する処理を削除した。BackendのDB、アプリsource、runtimeは`lws-backend-data` Named Volumeに保持し、アプリの永続データはComposeで宣言したLWS所有Named Volumeだけに保持する。開発時のファイル同期は相対pathのDocker Compose Watchを推奨する。
FilesChanged: infrastructure/compose.yaml, backend/compose.go, backend/runtime.go, backend/applications.go, backend/backend_test.go, docs/Infrastructure仕様書.md
Verification: go test ./backend/...
Related: ADR-002, CHG-025
CurrentValue: current
ValidityScope: 登録アプリのsource検証、Compose生成、Backend保存領域
