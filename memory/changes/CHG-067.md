# CHG-067: Backend永続ログ収集・検索・SSE配信を実装する

Status: SHIPPED
Reason: Dockerログ、Operation出力、LWS基盤ログを再起動後も検索・再開可能にし、直接のDocker CLIログSSEを廃止する。
Change: `log_entries` migration、opaque cursorの時刻順検索、secretマスク、保持期限・容量削除、一覧/SSE APIを追加した。Docker SDKの`RuntimeMonitor`がLWS所有labelとinstallation IDで限定したcontainerのeventとstdout/stderrを収集する。OperationのGit・Compose出力はタスク名付きで逐次保存する。全Compose serviceへ所有labelを付け、複数serviceログを収集可能にした。Dashboardのログ購読は永続ログAPIへ移行した。
