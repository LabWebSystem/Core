# CHG-099: AlmaLinuxインストールQAのDNF待ち時間を削減する

Status: SHIPPED
Reason: 自己完結Robot QAのAlmaLinuxインストールケースがGitHub Actionsで約142秒かかり、毎回の前提パッケージ導入とローカルRPM導入時のリポジトリmetadata取得が重複していたため。
Change: AlmaLinux 9のQA fixtureは標準イメージに含まれるcurlを使い、rootからcheckout済みinstall.shを直接実行する。不要なca-certificates、curl-minimal、sudoのDNF導入とraw GitHubからのスクリプト取得を除去する。インストーラーはRPMローカルファイルをDNFで導入するとき全リポジトリを無効にし、現行RPMの外部依存がない契約を利用してmetadataのネットワーク取得を省く。RPM選択のモックテストでDNF引数を確認する。
FilesChanged: qa/resources/install.resource, scripts/install.sh, scripts/test.sh
Verification: AlmaLinux前処理のDNF導入32.3秒、rawスクリプト取得0.38秒、Release API取得0.36秒、RPM取得0.76秒を計測した。クリーンなAlmaLinux 9でrepo metadataを有効にしたローカルRPM導入ケースは29.3秒、repoを無効化した変更後ケースは3.64秒（約88%短縮）。`mise run test installer`と`mise run qa-current`。
Related: ADR-001, ADR-009, CHG-049
CurrentValue: current
ValidityScope: AlmaLinux用RPMインストールとRobot Framework受け入れテスト
