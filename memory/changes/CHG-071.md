# CHG-071: 複数行JSONログをDashboardで構造化表示する

Status: SHIPPED
Reason: Backendが行単位で保存したJSON形式のコンテナ出力が、`{`や`}`だけの独立行として表示され、内容を読み取れなかった。
Change: 同一component、service、container、level、task名の連続ログをJSONとして復元できた場合だけ一つの構造化ログへまとめ、折りたたみ表示した。Backendが各行へ付与する`[Compose検証]`のようなtask名はJSON判定前に分離する。JSONとして完結しない通常ログは結合しない。
FilesChanged: dashboard/src/App.tsx, dashboard/src/styles.css, dashboard/src/App.test.tsx
Verification: npm --prefix dashboard run lint、npm --prefix dashboard test -- --run、Impeccable detector
Related: ADR-013, CHG-067, CHG-070
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Dashboardアプリ運用ログの表示
