# CHG-087: lwsctlの状態表示と再帰ライフサイクル操作を拡張する

Status: SHIPPED
Area: lwsctl lifecycle
Reason: LWS本体のバージョン確認、アプリを含む停止・撤去、およびlocalhostを使ったローカル起動が必要になったため。
Change: `status`へ現在のlwsctlバージョン表示を追加した。`stop`と`down`へ`-r`/`--recursive`を追加し、LWS所有かつinstallation ID一致のアプリcontainer・edge networkを再帰対象にした。`down --recursive --purge`ではアプリのLWS所有volumeも削除し、非再帰操作はLWS本体だけを対象にした。LWS本体の撤去はComposeへ委譲し、Docker実装差のあるlabel否定フィルターを使わない。ベースドメイン検証で`localhost`を許可した。
