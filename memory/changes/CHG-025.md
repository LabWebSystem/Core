# CHG-025: 未信頼sourceと実効Composeの検証境界を強化する

Status: SHIPPED
Reason: Git取得後のsource treeとDockerへ渡す実効Composeに、外部参照やホスト資源への危険な指定が残ると、Backendの責務境界を越えてしまうため。
Change: manifestのネストしたschema・duplicate・型を検証し、source treeのsymlink、Composeのduplicate key、実効Composeのbind/匿名volume、tmpfs、host namespace、host port、外部network/volumeを拒否する。named volumeは保持可能なアプリ資源として許可する。
FilesChanged: backend/validate.go, backend/source.go, backend/compose.go, backend/backend_test.go
Verification: go test ./backend/..., mise run test backend-http, mise run lint
Related: ADR-003, CHG-024
CurrentValue: current
ValidityScope: source・manifest・Compose検証
