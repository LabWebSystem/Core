# CHG-030: フェーズ3のOperation・source・Docker境界を実装する

Status: SHIPPED
Reason: フェーズ3の先行条件である同一app競合、source切替失敗時の復元、環境変数反映、LWS所有Docker資源の境界が未完成だったため。
Change: Operationの同一app競合とrequest fingerprintを永続化し、migration 002を追加した。workerの最大2並列と競合をテストした。source swapをold退避・復元可能にし、Compose検証失敗時に旧sourceを復元する。secretを復号してapp.envを0600で生成し、overrideへservice・named volumeの所有labelを付与する。edge network、Caddy接続、volume削除、Compose project containerの所有確認を追加した。
FilesChanged: backend/migrations/002_operation_fingerprint.sql, backend/operations.go, backend/worker.go, backend/source.go, backend/runtime.go, backend/docker.go, backend/compose.go, backend/http.go, backend/backend_test.go, backend/cmd/lws-backend/main.go
Verification: mise run test, mise run lint, mise run check-openapi, mise run build, docker compose -f infrastructure/compose.yaml config, git diff --check
Related: ADR-003, CHG-029
CurrentValue: current
ValidityScope: フェーズ3のOperation、source、環境変数、Docker所有境界
