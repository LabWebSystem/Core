# CHG-077: アプリ資源と環境変数の管理情報をDashboardへ追加する

Status: SHIPPED
Reason: 名前付きVolume、アプリ専用edge network、デバイス利用ポリシーが管理画面から確認できず、環境変数はsecretを保持したまま編集・削除できなかったため。
Change: Configuration APIはCompose由来の名前付きVolume、LWS所有edge network、デバイス割り当て禁止ポリシー、変数の必須・既定値・設定済み状態を返す。非secret値は管理画面へ返し、secret値は非表示のまま`keep`指定で保持する。設定更新は要求に含まれない既存変数を削除する。Dashboardはリソースを表示し、環境変数の追加・更新・削除と対象を示す確認を提供する。
FilesChanged: backend/applications.go, backend/http.go, backend/openapi.yaml, backend/openapi.gen.go, backend/cmd/lws-backend/main.go, backend/backend_test.go, dashboard/src/App.tsx, dashboard/src/App.test.tsx, dashboard/src/api/client.ts, dashboard/src/api/schema.ts, dashboard/src/styles.css
Verification: `go test ./backend/...`、`npm --prefix dashboard run lint`、`npm --prefix dashboard test -- --run`、`npm --prefix dashboard run build`、`mise run verify fast`、Impeccable detector
Related: ADR-002, ADR-005, ADR-012, CHG-025, CHG-030
CurrentValue: current
FutureRelevance: reusable
ValidityScope: アプリ資源の可視化とDashboardの環境変数編集
