# CHG-063: LWSのプロダクト文脈を定義する

Status: SHIPPED
Reason: Dashboardを含む今後のプロダクト・デザイン作業で、利用者、目的、制約、表現方針を一貫して判断できる正本が必要なため。
Change: `PRODUCT.md`を追加し、研究室・家庭内LANの管理者を対象とするLWSの目的、非専門的な日本語操作という位置付け、重厚な認証を現段階で実装しない制約、UI方針を定義した。Impeccableの画面制作既定をcode-firstとして保存した。
FilesChanged: PRODUCT.md, .impeccable/config.json
Verification: Impeccableの`init`手順に従い、利用者からプロダクト方針と制作方式を確認した。
Related: ADR-001, ADR-002, ADR-011
CurrentValue: current
ValidityScope: LWSのプロダクト・Dashboard・ユーザー向け文書
