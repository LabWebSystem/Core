# CHG-026: 設定値のsecret保護とHTTPエラー契約を強化する

Status: SHIPPED
Reason: APIから受け取ったsecretを平文で永続化すると、DB漏えい時の影響が大きく、状態変更の途中失敗では設定の部分適用も起きるため。
Change: secret変数をAES-GCMで暗号化して保存し、secret鍵がない場合は保存を拒否する。設定更新を事前検証後のtransactionへまとめ、NUL値・不正Content-Type・DB利用不可を拒否する。HTTPエラーのstatusとdetailsをHTTPコードに対応させる。
FilesChanged: backend/http.go, backend/applications.go, backend/backend_test.go, backend/cmd/lws-backend/main.go
Verification: go test ./backend/..., mise run test backend-http, mise run lint, memadr check, memadr index
Related: ADR-003, CHG-025
CurrentValue: current
ValidityScope: Backend設定APIとHTTPエラー
