# CHG-061: テスト用Dockerイメージを実行後に削除する

Status: SHIPPED
Reason: QAとDashboard検証の繰り返しでテスト用Dockerイメージが残り、開発環境のディスクを圧迫していたため。
Change: 共通ラッパーがDockerイメージIDの実行前後差分だけを削除する。`qa`、`qa-current`、`qa-lifecycle`、Dashboardイメージ検証、実Docker統合テストに適用した。`lwsctl update`はComposeの固定digestを`docker image inspect`で確認し、すべてローカルにある場合は`compose pull`を行わない。
