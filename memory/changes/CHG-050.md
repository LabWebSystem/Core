# CHG-050: 機能テストの環境依存失敗をskipへ分類する

Status: SHIPPED
Reason: `mise run qa`の結果で、LWS未起動やCompose healthcheck不成立を未実装FAILと混同しないため。
Change: AlmaLinux installテストで既存の`curl-minimal`と競合しないよう依存パッケージを修正した。API suiteはLWSの公開経路へ接続して検証し、接続できない場合はFAILとして原因を記録する。lifecycle suiteは一時ComposeでBackendをローカルbuildし、Backend healthcheck不成立を実装・環境の問題としてFAILにする。
FilesChanged: qa/resources/install.resource, qa/resources/api.resource, qa/resources/lifecycle.resource
Verification: `mise run qa`（修正前の環境分類確認）、`mise run qa-lifecycle`（3 passed）、`mise run qa-current`（6 passed）、`mise run qa-docs`、`mise run lint`、`memadr check`
Related: ADR-009, CHG-048, CHG-049
CurrentValue: current
