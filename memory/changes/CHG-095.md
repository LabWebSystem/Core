# CHG-095: Dashboardを削除不可のシステムアプリへ移行する

Status: SHIPPED
Area: Backend / Dashboard / Infrastructure / documentation
Reason: Dashboardを基盤Compose serviceとして扱わず、登録アプリと同じ実行・公開フローに統一し、管理画面の削除を防ぐため。
Change: Dashboard serviceを基盤Composeから外し、Backend起動時にバージョン固定imageを参照するシステムアプリとして登録・起動する。`is_system` migrationと削除trigger、削除・登録解除・設定変更のAPI保護、OpenAPIの`isSystem`、Dashboard UI表示、Reserved subdomain、Dashboard開発用Vite system appを追加した。開始・停止は通常アプリと同様に許可し、Dashboardリリースimageのビルドと配布は維持する。
