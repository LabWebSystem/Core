# CHG-011: miseの表示形式に依存しないリリーステスト

Status: SHIPPED
Reason: GitHub Actions上の`mise`が`mise run --dry-run`の表示形式を変え、リリース操作の契約と無関係な完全一致検証でリリースWorkflowが失敗した。
Change: `scripts/release.sh`をモックGitHubで直接実行する既存検証を正本とし、`mise`のdry-run表示文字列への依存を削除する。
FilesChanged: scripts/test.sh
Verification: `mise run lint`、`mise run test`、`mise run package`
Related: CHG-010
CurrentValue: current
ValidityScope: CoreおよびSDKのリリース前テスト
