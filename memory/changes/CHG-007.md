# CHG-007: lwsctlをGoバイナリとして配布する

Status: SHIPPED
Reason: `lwsctl`をシェルスクリプトではなく単一の実行バイナリとしてビルド・配布できるようにする必要があるため。
Change: 既存の6コマンドとライフサイクル契約をGo標準ライブラリへ移植し、`mise`管理のGoツールチェーンでLinux amd64バイナリをビルドする。`.deb`と`.rpm`には同一の`lwsctl`バイナリを配置し、ルートおよび各コマンドのヘルプを追加する。
FilesChanged: go.mod, cmd/lwsctl/main.go, scripts/build-lwsctl.sh, scripts/package.sh, scripts/lint.sh, scripts/test.sh, mise.toml, packaging/lws.spec.in
Verification: `mise run lint`、`mise run test`、`mise run package`
Related: ADR-001, CHG-003, CHG-004, CHG-006
CurrentValue: current
ValidityScope: LWS CLIのビルド、配布、ライフサイクル操作
