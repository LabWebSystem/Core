# CHG-102: mDNSの公開ホスト名を単一ラベルのハイフン形式に統一する

Status: SHIPPED
Area: Backend / CLI / Dashboard / Infrastructure
Reason: `dashboard-test.local`のようにホスト名が3ラベル以上になると、一部のmDNSクライアントで名前解決できないため。
Change: Avahi用hosts、Caddyfile、Backendの許可Host・Origin、DashboardのアプリURL、CLIとComposeのhealthcheckを`<name>-<base-domain>`形式に揃える。複数ラベルのbase domainは末尾ラベルより前をハイフンで連結し、生成する公開名のDNS長を検証する。利用者向け資料とQA用Compose生成も新形式へ更新する。
FilesChanged: backend, internal/hostname, cmd/lwsctl, dashboard, infrastructure, qa, scripts/prepare-lifecycle-compose.py, README.md, docs, AGENTS.md
Verification: `git diff --check`。テスト・lintは実行していない。
Related: ADR-016
CurrentValue: current
FutureRelevance: reusable
ValidityScope: LWSの`.local` mDNS公開名とReverse Proxy Host
