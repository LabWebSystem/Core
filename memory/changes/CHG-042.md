# CHG-042: LWSリリースWorkflowのBackend build contextとActionを修正する

Status: SHIPPED
Reason: Backend Dockerfileがリポジトリルートの`go.mod`、`go.sum`、`version`を参照する一方、Workflowが`backend/`だけをbuild contextにしていたため、image buildが失敗していた。またDocker loginとartifact ActionにNode.js 20系が残っていた。
Change: Backend imageを`--file backend/Dockerfile .`でルートcontextからbuildするようにした。`docker/login-action`をv4、artifact upload/downloadをNode.js 24対応版へ更新した。
FilesChanged: .github/workflows/release-lws.yml
Verification: docker build --file backend/Dockerfile --tag lws-backend-release-check .
Related: CHG-040, CHG-041, docs/Infrastructure・Backend実装計画.md
CurrentValue: current
ValidityScope: LWSリリースWorkflow、Backend image build、GitHub Actions runtime
