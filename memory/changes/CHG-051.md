# CHG-051: API受け入れテストをCaddy公開経路へ接続する

Status: SHIPPED
Reason: Backend内部の8080番ポートをホストへ公開せず、LWS利用者と同じAPI公開経路を機能テストするため。
Change: APIテストのデフォルト接続先を`127.0.0.1:8080`から`127.0.0.1:80`へ変更し、`Host: api.<base-domain>`を付与してCaddyからBackendへ転送する構成にした。API未起動時の自動SKIPを廃止し、環境不備もFAILとして記録する。通常の`qa`から`live`タグを除外し、起動済みLWSを要求するAPIテストは`qa-live`へ分離した。Lifecycleテストは一時ComposeのBackend image固定参照を外し、ワークスペースのBackendをbuildして実際のhealthcheckとCaddy経路を起動する。
FilesChanged: qa/resources/api.resource, qa/resources/lifecycle.resource, qa/README.md, docs/機能テストルール.md
Verification: `mise exec -- uv run --project qa robot --dryrun --outputdir /tmp/lws-qa-dryrun-caddy qa/suites`, `mise run qa`（33 tests, 12 passed, 21 planned failures）、`mise run qa-lifecycle`（3 passed）、`mise run qa-current`（6 passed）、`mise run lint`、`git diff --check`
