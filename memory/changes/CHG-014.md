# CHG-014: lwsctlの実行環境撤去をdownへ改名

Status: SHIPPED
Reason: `lwsctl uninstall`はAPT/DNFによるパッケージ削除と混同しやすく、CLIの責務境界が不明確だった。
Change: `uninstall`を`down`へ置き換えた。`stop`はCompose実行環境を停止し、`down`はコンテナとnetworkを削除する。`down --purge`だけが設定と状態を削除し、パッケージの削除はAPT/DNFへ委譲する。
FilesChanged: cmd/lwsctl, scripts/test.sh, README.md, docs, packaging, ADR-001, ADR-002
Verification: mise run lint, mise run test, mise run package
Related: ADR-001, ADR-002, CHG-004
CurrentValue: current
ValidityScope: lwsctlとLWSパッケージのライフサイクル
