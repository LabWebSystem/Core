# CHG-079: 設定レイヤーとリソースプールを追加する

Status: SHIPPED
Reason: デバイスpathの変動を吸収しつつ、通常のCompose互換性を維持し、設定前の即時起動を防ぐため。
Change: Composeの`devices`を受理し、LWSデバイスプールのbindingから生成overrideへ現在の`/dev` pathを反映する。Backend imageへ`udevadm`を含め、ホストの`/dev`と`/run/udev`をread-onlyでmountして物理候補を検出する。通常はUSB由来のユーザーデバイスだけを表示する。`hidraw`など子nodeにUSB属性が継承されない環境では親USB pathも分類へ利用し、serialがないUSB機器も`usb topology`識別子として候補表示する。管理者が「システムデバイスを表示」を選ぶと、`/dev`配下のchar/block device nodeを列挙し、udevのvendor/modelまたは親USBのproductを人間向け名称として表示する。起動前とプール閲覧時に再検出するため、USB port変更後もcurrent pathを更新する。初回登録は`CONFIGURING`で停止し、必須環境変数とdevice bindingを満たした開始だけを許可する。Dashboardでは物理デバイスの登録、アプリごとのdevice選択、Volume・Network・Deviceプールを提供する。

Verification: `go test ./backend/...`、`npm --prefix dashboard run lint`、`npm --prefix dashboard run build`、`memadr check`
