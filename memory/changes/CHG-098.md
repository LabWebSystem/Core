# CHG-098: Core品質ゲートをActionsで並列実行しローカル入口をremote化

Status: SHIPPED
Reason: Core品質ゲートはローカルで直列実行され、Actions側にもprofile選択・公開段階の定義が分かれていた。長い全検証をGitHub Actionsに集約し、独立検証を並列実行して短縮する必要があった。
Change: 再利用可能なCore品質Workflowに検証profileと依存関係を集約し、fast 4項目とfull QA 5項目をGitHub Actionsの別runnerで実行する。通常のPR・ブランチpushはfast、手動とLWS releaseはfullとする。`mise run verify`をpush済みclean commitのdispatch・監視・artifact取得入口へ変更し、test実行定義の重複を除く。release品質ゲートからpackageを分離し、image digest取得後に一度だけ生成する。
FilesChanged: .github/workflows/ci.yml, .github/workflows/quality.yml, .github/workflows/release-lws.yml, mise.toml, scripts/verify.sh, scripts/test-verify-dispatch.sh, scripts/test-quality-architecture.sh, scripts/mise.lib.toml, README.md, docs/, memory/decisions/ADR-010.md, memory/decisions/ADR-019.md
Verification: `mise tasks validate`、`mise run lint`、`mise run test fast`、`scripts/test-quality-architecture.sh`、`scripts/test-verify-dispatch.sh`、PyYAMLによる全Workflow構文・品質job graph検査、`git diff --check`。
