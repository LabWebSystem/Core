# CHG-098: LWSイメージをバージョンtagで運用しテスト用image削除を限定する

Status: SHIPPED
Area: Infrastructure / CLI / CI / test
Reason: LWSリリースではバージョンtagを正本とし、不要なdigest注入と、並行作業中に無関係なDocker imageを消す危険をなくすため。
Change: Backend・Dashboard・AvahiはLWS release version tag、Caddyは固定バージョンtagを使う。`lwsctl update`はComposeのimageをpullする。package生成はCompose定義をそのまま配置する。image cleanup wrapperは実行固有labelを付けたテストimageだけを削除し、共有imageは残す。
