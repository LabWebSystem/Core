# CHG-009: デプロイからSDKをGitHub Packagesへ公開する

Status: SUPERSEDED
Reason: SDK公開用Workflowは存在したが、`mise run deploy`がSDKタグを発行しないため、LWSリリースとSDK公開を一つのデプロイ操作で完了できなかった。
Change: `deploy`に必須の`--sdk-version`を追加し、LWSタグとSDKタグを発行して両方のWorkflow完了を待機する。SDK Workflowはリリースタグのバージョンを`package.json`へ同期してGitHub Packagesへ公開する。SDKバージョンはLWS本体から独立して指定し、公開済みSDKタグの再利用は拒否する。この方式はCHG-010で置き換えられた。
FilesChanged: scripts/deploy.sh, .github/workflows/release-sdk.yml, README.md
Verification: `mise run lint`、`mise run test`、`mise run package`、`memadr check`、`memadr index`
Related: ADR-001, CHG-005
CurrentValue: historical
ValidityScope: LWSデプロイとSDKのGitHub Packages公開
