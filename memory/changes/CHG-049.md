# CHG-049: インストール受け入れテストをroot隔離実行へ変更する

Status: SHIPPED
Reason: インストール機能を固定FAILではなく、実際のcurlインストーラーとroot権限で検証しつつ、開発ホストを変更しないため。
Change: Ubuntu、AlmaLinux、非対応OSのテストを一時Dockerコンテナ内で実行するRobotキーワードへ置き換えた。コンテナ内では`curl -fsSL .../scripts/install.sh | sudo bash`を実行し、`--rm`で終了後に削除する。`mise run qa`にはRobotの`--nostatusrc`を設定し、テストが完遂した場合はFAIL項目を進捗結果へ残したままコマンドを成功させる。
FilesChanged: qa/resources/install.resource, qa/suites/v1/cli.robot, mise.toml, qa/README.md, docs/機能テストルール.md
Verification: `mise exec -- uv run --project qa robot --dryrun --outputdir /tmp/lws-qa-dryrun-install qa/suites/v1/cli.robot`, `mise run qa-current`, `mise run lint`, `git diff --check`
Related: ADR-009, CHG-046, CHG-048
CurrentValue: current
ValidityScope: Robot Frameworkのインストール受け入れテストとqa実行status
