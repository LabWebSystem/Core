# CHG-037: Backendの未検証境界を自動テストで補完する

Status: SHIPPED
Reason: 起動後の手動確認へ進む前に、HTTP契約、DB利用不可、secret・config権限、未定義operationの自動検証が不足していたため。
Change: Application一覧のOpenAPI必須項目を返すよう修正した。DB未利用時の主要read・state changeを503で拒否し、未定義operationを404で拒否した。既存secret keyとconfig.envのsymlink・権限を検証し、OpenAPIの設定取得404契約を追加した。
