# CHG-072: 登録失敗の原因をBackend正本から表示する

Status: SHIPPED
Reason: 重複した公開名や存在しないGit refで登録に失敗しても、Dashboardが一律の失敗文言を表示し、原因を判断できなかった。
Change: 登録APIの失敗文言をDashboardへ伝え、Operation終端時は永続Operationを再取得してerrorMessageを表示する。Git cloneのremote branch/ref不在は生出力を返さず、安全な日本語原因へ分類する。
