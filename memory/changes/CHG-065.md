# CHG-065: Dashboardのローカル結合確認環境を追加する

Status: SHIPPED
Reason: Dashboardの実画面をCaddy経由で開き、Backend APIとの接続を既存LWSのport・Compose資源から隔離して確認できる必要があるため。
Change: `dashboard.lws.localhost:18180`でDashboard、Caddy、Backendを起動するCompose上書きと`mise` taskを追加した。通常Composeの公開portは環境変数で既定値を保ち、開発taskだけ18180/1053を指定する。開発環境は専用project、volume、networkを使い、Dashboard Originはportを含めてBackendへ明示した。開発時はdigest付きのリリースimage参照をローカルtagへ上書きし、Compose buildがdigestをtagに使わないようにする。専用volumeを含めて初期状態へ戻す明示的なreset taskも追加した。
FilesChanged: infrastructure/compose.dashboard-dev.yaml, mise.toml, README.md
Verification: Docker Compose起動後、DashboardのHTMLと同一OriginのAPI応答を確認する。
Related: ADR-002, ADR-003, ADR-012, CHG-064
CurrentValue: current
ValidityScope: ローカルDashboard結合確認
