# CHG-094: AvahiコンテナでLWSのmDNSを提供する

Status: SHIPPED
Area: Infrastructure / Backend / CLI / release
Reason: LWSのアプリURLを`.local` mDNSでLANへ公開し、通常DNSサーバー機能と53番ポート依存をなくすため。
Change: CoreDNSのサービス・Corefile・専用イメージを削除し、Avahiデーモンを含むLWSイメージを追加した。Backend生成hostsをAvahiの静的ホスト定義として使い、更新時は所有確認済みAvahiコンテナを再起動する。`lwsctl start`は`.local`のbase domainを受け付け、80/tcpとUDP 5353の競合を検査する。UDP 5353が使用中なら既存サービスへ触れず起動を失敗させる。release workflowとDebian/RPM packageへAvahiイメージdigestを反映した。
FilesChanged: .dockerignore, infrastructure/Dockerfile.avahi, infrastructure/avahi-daemon.conf, infrastructure/avahi-entrypoint, infrastructure/compose.yaml, infrastructure/compose.dev.yaml, infrastructure/compose.dashboard-dev.yaml, backend/derived_manager.go, backend/docker.go, backend/runtime_monitor.go, backend/openapi.yaml, backend/openapi.gen.go, cmd/lwsctl/commands.go, cmd/lwsctl/config.go, cmd/lwsctl/compose.go, .github/workflows/release-lws.yml, scripts/package.sh, scripts/test-infrastructure.sh, qa/resources/lifecycle.resource, README.md, docs/Infrastructure仕様書.md
