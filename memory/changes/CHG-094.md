# CHG-094: ZIPとmanifestなしアプリを取り込む

Status: SHIPPED
Area: Backend / Dashboard / アプリ登録
Reason: GitHubで管理されていないアプリやLWS manifestを持たないComposeアプリを登録・更新できるようにするため。
Change: GitHubまたはZIPの一時取り込みと候補確認を追加し、利用者が選択したCompose・公開先をSQLiteへ保存する。manifestの値は入力の初期値とし、manifestなしでも登録・起動できる。ZIPは安全に展開し、再アップロードによる更新と失敗時の旧状態復元を行う。Dashboardは取得元とmanifestの有無に応じた確認・設定画面を表示する。
