# CHG-056: 品質ゲートを高速・QA・リリースへ分離し結果を集約する

Status: SHIPPED
Reason: 既定の`verify`が隔離Robot QAまで毎回実行して遅く、Bash・Go・npm・Robotの出力形式と結果保存先が分散していたため。
Change: `verify`をfast、qa、releaseの3プロファイルへ分離した。fastは静的検査、Core高速テスト、SDK、Dashboardだけを実行し、qaはCore統合テストと隔離Robot QAを追加する。品質ゲート実行器は端末へ`VERIFY_ITEM`形式の要約を出力し、全検証の結果と生ログを日付ごとの単一Markdownへ保存する。
