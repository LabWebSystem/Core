# BUG-012: 品質ゲート構造検査が未管理のrgへ依存する

Status: VERIFIED
Area: test
Symptom: `rg`がPATHにない開発環境で`mise run verify`が構造検査の開始時に失敗する。
Cause: 構造検査スクリプトが`mise`で管理していない`rg`を必須コマンドとして実行していた。
Fix: 構造検査を標準の`grep`だけで実行するように変更した。
Verification: `rg`をPATHへ置かない環境で`scripts/test-quality-architecture.sh`が成功すること、`mise run test architecture`が成功すること。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: 品質ゲート構造検査の外部コマンド依存
ResolvedBy: CHG-054
Related: ADR-010, CHG-053, CHG-054
