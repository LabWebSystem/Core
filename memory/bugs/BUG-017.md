# BUG-017: 正常なstderrと複数行ログがerror表示される

Status: VERIFIED
Area: logging
Symptom: Git、Docker Compose、nginxの正常なstderr出力や、複数行JSONがDashboardでerrorまたは複数行として表示される。
Cause: 外部コマンドのstderrを無条件にerrorとし、アプリログもstderr経由の出力をerrorとして保存していた。保存時の改行正規化もなかった。
Fix: 外部コマンドは終了結果をerror判定の正本とし、ログ本文のseverity markerを補助的に解析する。保存時に改行を空白へ正規化し、Dashboardでは連続JSONをコンパクトな構造化ブロックとして表示する。
Verification: ログレベル・1行保存のBackendテスト、Dashboardテスト、Impeccable detector、`mise run verify fast`。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: Backend外部コマンド・Dockerアプリログ、Dashboardログ表示
