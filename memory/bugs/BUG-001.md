# BUG-001: AlmaLinuxでOSバージョンをLWSリリース版として参照する

Status: VERIFIED
Area: installer
Symptom: AlmaLinuxの`/etc/os-release`を読み込んだ後、インストーラーが`lws-v9.8 (Olive Jaguar)`のような存在しないLWSリリースを取得しようとする。
Cause: LWSリリース指定と`/etc/os-release`の両方で`VERSION`という変数名を使用していた。
Fix: LWSリリース指定を`LWS_RELEASE_VERSION`へ変更し、OS情報の変数と分離した。
Verification: AlmaLinux形式の`os-release`を使うインストーラーテストでGitHub Releasesの`latest` APIを参照することを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: `/etc/os-release`を読み込むLWSインストーラー
ResolvedBy: CHG-002
Related: CHG-001
