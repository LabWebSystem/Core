# BUG-014: 初回起動前にupdateを実行できない

Status: VERIFIED
Area: cli
Symptom: `lwsctl start`を一度も実行していない環境で`lwsctl update`を実行すると、設定がないことを理由に更新できない。
Cause: `update`が設定ファイルの読み込みを必須にしており、未設定時に更新処理へ進めなかった。
Fix: 設定がない場合もpackageとDocker imageを更新できるようにし、設定の作成とコンテナ起動は行わない。
Verification: 初回起動前の`update`がpackage更新と`compose pull`を実行し、設定ファイルと`compose up`を作らないCLIテストを追加して`mise run test cli`で確認する。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: lwsctlの初回起動前更新
