# BUG-003: stopが保存済みのベースドメインをComposeへ渡さない

Status: VERIFIED
Area: cli
Symptom: 設定済みのLWSでも`lwsctl stop`がComposeの`LWS_BASE_DOMAIN`未設定エラーで失敗する。
Cause: `stop`が`config.env`を読み込まずにComposeを実行していた。
Fix: `stop`のCompose実行前に設定を読み込み、設定がない場合も冪等に停止処理を継続する。
Verification: モックDockerを使い、`stop`が保存済みのベースドメインを渡して`down`を呼ぶことを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: LWSの停止とアンインストール
ResolvedBy: CHG-004
Related: BUG-002, ADR-001
