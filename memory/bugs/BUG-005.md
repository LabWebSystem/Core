# BUG-005: checkoutなしのReleaseジョブでリポジトリを解決できない

Status: VERIFIED
Area: release
Symptom: LWSリリースの最終ジョブが`fatal: not a git repository`で失敗し、GitHub Releaseを作成できない。
Cause: artifactだけを取得する最終ジョブにcheckoutがなく、`gh release create`が作業ディレクトリからリポジトリを自動判定しようとした。
Fix: `gh release create`へGitHub Actionsの`GITHUB_REPOSITORY`を`--repo`として明示する。
Verification: `lws-v0.1.0`のLWSリリースWorkflow 31895492996でGitHub Release作成まで成功した。
FutureRelevance: watch
CurrentValue: current
ValidityScope: LWSリリースWorkflowの最終Releaseジョブ
ResolvedBy: CHG-012
Related: CHG-012
