# BUG-019: CONFIGURINGからの起動で公開経路が生成されない

Status: VERIFIED
Area: backend-runtime
Symptom: 初回設定後にアプリcontainerは起動するが、アプリsubdomainへアクセスしても空の応答になり、生成Caddyfileにアプリ経路が含まれない。
Cause: START/REBUILDが`registration_state`をACTIVEへ更新する前に`syncDerived`を実行し、DerivedManagerがACTIVEアプリだけを公開対象にしていた。
Fix: CONFIGURINGからの起動では、Compose起動後にACTIVEへ遷移してから公開設定を同期し、同期失敗時は元の状態へ戻す。
Verification: `mise run test backend`、既存のDashboard開発環境で生成CaddyfileとアプリURLを確認。
FutureRelevance: watch
CurrentValue: current
ValidityScope: START/REBUILDの公開設定同期
ResolvedBy: CHG-082
