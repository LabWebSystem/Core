# BUG-011: CoreDNSが生成hostsを読み取れない

Status: VERIFIED
Area: infrastructure
Symptom: non-rootで動作するCoreDNSが、Backendの生成したhostsを読み取れず、LWS管理ドメインがNXDOMAINになる。
Cause: 生成ディレクトリを0700、hostsとCaddyfileを0600で作成していた。
Fix: CoreDNSとCaddyが読む派生設定のディレクトリを0755、ファイルを0644で生成し、既存ディレクトリも再調整する。
Verification: 派生設定の権限テスト、Backendテスト、Infrastructure統合テストで確認する。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: Backendの生成設定とCoreDNS/Caddyの実行ユーザー
ResolvedBy: v0.1.7
