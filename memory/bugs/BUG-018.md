# BUG-018: purge完了後にOperation履歴を取得できない

Status: OPEN
Area: backend-operation
Symptom: 完全削除が完了するとアプリ記録と外部キーcascadeでOperation記録も削除され、Dashboardが完了Operationを取得すると404になる。
Cause: purgeがアプリ記録を物理削除する際、アプリに紐づくOperation履歴も同時に削除される設計になっている。
Fix: 未実装。purge完了をDashboardが観測できるOperation保持または削除前の終端イベント通知を検討する。
Verification: アプリpurge後のOperation参照が404になることを実環境で確認。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: アプリpurgeとDashboardのOperation表示
Related: ADR-004, ADR-013
