# BUG-013: 未作成edge networkをDockerエラーとして扱う

Status: VERIFIED
Area: backend
Symptom: 初回アプリ登録でedge networkが未作成の場合に、Operationが`Docker資源を確認できません`で失敗する。
Cause: `docker network inspect`の未存在メッセージは標準エラーへ出力されるが、実行器は標準出力だけを回収していた。加えて、Dockerの`not found`を未存在として判定していなかった。
Fix: コマンド失敗時も標準エラーを回収し、`no such`と`not found`をDocker資源未存在として扱う。
Verification: OSRunnerの標準エラー回収テスト、未作成networkの作成テスト、`mise run test`で確認する。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: BackendによるDocker resourceのinspectとedge network作成
ResolvedBy: CHG-055
Related: ADR-005, CHG-055
