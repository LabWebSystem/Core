# BUG-021: アプリのリビルドで最新イメージを反映しない

Status: VERIFIED
Area: backend-runtime
Symptom: Dashboardのリビルド操作が既存コンテナを再作成せず、古いローカルイメージを使い続ける可能性がある。
Cause: REBUILDが`docker compose up -d`だけを実行し、image pull、build、強制container再作成を要求していなかった。
Fix: REBUILDで`pull`、`build --pull`、`up -d --force-recreate --remove-orphans`を順番に実行する。
Verification: Backendのコマンド列テストと`mise run test backend`、`mise run lint`で確認。
FutureRelevance: watch
Decision: アプリのリビルドは、登録済みsourceを対象にDockerイメージを更新してからcontainerを強制再作成する。
ResolvedBy: CHG-084
CurrentValue: current
ValidityScope: BackendのアプリREBUILD Operation
