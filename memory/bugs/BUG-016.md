# BUG-016: 登録解除Operationが開始されない

Status: VERIFIED
Area: backend-operation
Symptom: Dashboardから登録解除すると、Operationが`QUEUED`（開始待ち）のまま進まない。
Cause: 登録解除APIはOperationを作成するだけで、同一アプリのWorker待機列へ投入していなかった。さらに、source欠損時はDocker資源が既にない場合もCompose停止を必須としていた。
Fix: 登録解除APIでも他のアプリOperationと同じWorker投入処理を実行し、所有確認済みのDocker資源がないsource欠損状態を冪等に完了できるようにする。
Verification: 登録解除APIのOperationがWorkerへ渡るテスト、source欠損時の登録解除テスト、`mise run test backend`。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: Backendの登録解除API
ResolvedBy: CHG-073
Related: CHG-068, ADR-004
