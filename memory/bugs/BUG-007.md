# BUG-007: downが保存済みのベースドメインをComposeへ渡さない

Status: VERIFIED
Area: cli
Symptom: 設定済みのLWSで`lwsctl down --purge`が`LWS_BASE_DOMAIN`未設定エラーとなり、実行環境を撤去できない。
Cause: `down`が`config.env`を読み込まずにComposeを実行していた。
Fix: `down`のCompose実行前に設定を読み込み、設定がない場合は`start`を促すエラーを返す。
Verification: モックDockerを使い、`down`が保存済みのベースドメインとLWSバージョンを渡すことを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: LWSの実行環境撤去
ResolvedBy: CHG-015
Related: BUG-003, CHG-014, ADR-001
