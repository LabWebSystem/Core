# BUG-015: テストで取得したDockerイメージが残る

Status: VERIFIED
Area: quality-gate
Symptom: `mise run verify qa`やDashboardイメージ検証のたびに、テストで取得・作成したDockerイメージがホストに残り、ディスク使用量が増える。
Cause: テストのコンテナとCompose resourceは終了時に削除していたが、Dockerイメージの実行前後の差分を管理していなかった。
Fix: 実行前のイメージIDを記録し、テスト完了後にその時点で新規のIDだけを削除する共通ラッパーをQA、Dashboard検証、実Docker統合テストに適用する。
Verification: Dashboardビルドで新しいdangling imageが削除されること、`mise run verify qa`が成功することを確認する。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: Dockerを使う品質ゲートとテスト
ResolvedBy: CHG-061
Related: ADR-009, ADR-010, CHG-056, CHG-061
