# BUG-006: アーキテクチャ名なしのRPMをインストーラーが見つけられない

Status: VERIFIED
Area: installer
Symptom: AlmaLinux x86_64でGitHub Releaseの`lws-<version>.rpm`を取得できず、パッケージ未検出としてインストールに失敗する。
Cause: RPM成果物名にアーキテクチャが含まれていない一方、インストーラーは`x86_64`を含むRPM名だけを検索していた。
Fix: 新規RPM成果物を`lws-<version>.x86_64.rpm`として生成する。既存のアーキテクチャ名なしRPMはx86_64環境だけで互換対象として選択する。
Verification: x86_64名付きRPMと既存の名前なしRPMの両方を使うAlmaLinuxインストーラーテストが成功する。
FutureRelevance: watch
CurrentValue: current
ValidityScope: AlmaLinux系x86_64のLWSインストール
ResolvedBy: CHG-013
Related: CHG-001, CHG-002
