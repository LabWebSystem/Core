# BUG-020: 公開serviceのWebSocketが内部APIへ接続できない

Status: VERIFIED
Area: Backend / Docker Compose
Symptom: Compose Watchを使う開発用公開serviceから内部APIへのWebSocket接続が失敗する。
Cause: 公開serviceを外部用lws-edge networkへ追加する際、override側でのみ定義されたserviceの暗黙default networkを保持していなかった。
Fix: 全Composeソースから公開serviceのnetwork定義を解決し、生成overrideへdefault等の既存networkを引き継ぐ。
Verification: `mise run test backend` 成功。
FutureRelevance: watch
Decision: Composeのoverrideは公開networkを追加するが、元のnetwork接続を維持する。
ResolvedBy: CHG-083
CurrentValue: current
ValidityScope: 現行Compose公開経路
