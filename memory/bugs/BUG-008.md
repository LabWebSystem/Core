# BUG-008: updateが停止中のLWSを起動する

Status: VERIFIED
Area: cli
Symptom: `lwsctl stop`後に`lwsctl update`を実行すると、停止中だったLWSコンテナが起動する。
Cause: `update`が更新前の稼働状態を確認せず、常に`docker compose up -d`を実行していた。
Fix: パッケージ更新前に稼働serviceの有無を確認し、更新後は起動中だった場合だけ`up -d`を実行する。
Verification: モックDockerを使い、停止中では`up -d`を呼ばず、起動中では呼ぶことを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: lwsctl update
ResolvedBy: CHG-016
Related: ADR-001, CHG-014
