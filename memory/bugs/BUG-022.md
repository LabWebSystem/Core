# BUG-022: DashboardホストのSwagger UIがBackendへ転送されない

Status: VERIFIED
Area: Backend / Infrastructure
Symptom: Dashboard開発環境の`http://dashboard.lws.localhost:18180/swagger`を開いてもSwagger UIが表示されない。
Cause: DashboardホストのCaddy公開経路が`/api/*`だけをBackendへ転送し、OpenAPI仕様とSwagger UIの経路をDashboardへ送っていた。
Fix: 生成CaddyfileのDashboardホストに`/openapi.json`、`/swagger`、`/swagger/*`をBackendへ転送するpath matcherを追加した。
Verification: 生成CaddyfileのBackend転送経路を検査するBackendテスト、`mise run test backend`、`mise run test infrastructure`。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: DashboardホストからのBackendドキュメント公開
ResolvedBy: CHG-089
Related: ADR-002, ADR-003, CHG-088
