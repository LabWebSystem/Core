# BUG-004: 設定済みのLWSバージョンをComposeへ渡さない

Status: VERIFIED
Area: cli
Symptom: 新しいLWSパッケージを導入しても、Composeが既定の`0.1.0`イメージタグを参照する。
Cause: `config.env`から読み込んだ`LWS_VERSION`をexportしていなかった。また`update`がパッケージ更新を実行していなかった。
Fix: LWS版をパッケージ管理下の`/usr/share/lws/version`で管理し、`LWS_VERSION`をComposeへexportする。`update`はインストーラーを通じてAPT/DNFへ更新を委譲してから再起動する。
Verification: モック更新で新しい版情報を導入し、Composeがそのイメージタグを使うことを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: LWSの更新とイメージ取得
ResolvedBy: CHG-006
