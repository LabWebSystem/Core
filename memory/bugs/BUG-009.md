# BUG-009: 未設定時のstatusがCompose補間エラーを返す

Status: VERIFIED
Area: cli
Symptom: 設定がない状態で`lwsctl status`を実行すると、未設定を表示した後にComposeの`LWS_BASE_DOMAIN`未設定エラーで失敗する。
Cause: `status`が設定なしを表示した後もComposeの状態照会を続行していた。
Fix: 設定がない場合は、`start`を案内して正常終了する。
Verification: モックDockerを使い、未設定時の出力が2行だけでComposeを呼ばないことを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: lwsctl status
ResolvedBy: CHG-017
Related: BUG-007, ADR-001
