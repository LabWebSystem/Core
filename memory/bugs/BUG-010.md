# BUG-010: テストがCoreバージョンを変更したまま終了する

Status: VERIFIED
Area: test
Symptom: `mise run test`の実行後、`version/core`が`0.1.0`へ書き換えられる。
Cause: バージョン確認テストが固定値を設定するために`mise run version core 0.1.0`を実行し、復元していなかった。
Fix: バージョン確認テストは正本を変更せず、現在のCore/SDKバージョンを読み取って検証する。リリーステストも現在のバージョンを使う。
Verification: 任意のCoreバージョンで`mise run test`を実行しても`version/core`が変更されないことを確認する。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: scripts/test.shのバージョン・リリース検証
ResolvedBy: CHG-018
Related: CHG-010, CHG-011
