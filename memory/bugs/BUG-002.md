# BUG-002: 初回startでComposeへベースドメインを渡さない

Status: VERIFIED
Area: cli
Symptom: 初回の`lwsctl start`でベースドメインを入力しても、Composeが`LWS_BASE_DOMAIN`未設定として起動に失敗する。
Cause: `config.env`を書き込んだ後に、同じプロセスの`LWS_BASE_DOMAIN`をexportしていなかった。
Fix: 設定保存処理で`LWS_BASE_DOMAIN`をexportし、初回設定とドメイン変更の両方でComposeへ渡す。
Verification: 初回`start --domain example.internal`時にdocker実行環境へ`LWS_BASE_DOMAIN`が渡ることをテストする。
FutureRelevance: watch
CurrentValue: watch
ValidityScope: LWSの初回起動
ResolvedBy: CHG-003
Related: ADR-001
