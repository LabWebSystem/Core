# SUP-002: CoreDNS mDNS案をAvahi方式へ置き換える

Status: ACTIVE
Supersedes: CHG-093
Reason: LWSは`.local` mDNSだけを提供し、通常DNSやルーターDNSの代替を担わない方針になったため。CoreDNS方式は53番ポートと通常DNSの責務を持ち込み、既存DNSとの競合も増やす。
NewBaseline: ADR-016, CHG-094
CurrentValue: current
ValidityScope: LWSのmDNS構成とCoreDNS専用イメージ
ReactivatedIf: 通常DNS、外部DNS転送、またはmDNSを通さないネットワーク越しの名前解決が新要件になった場合のみ、旧案を比較対象として再評価する。
Related: ADR-002, ADR-013, CHG-093, CHG-094
