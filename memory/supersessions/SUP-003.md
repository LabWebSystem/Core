# SUP-003: mDNS公開名のドット区切り規則を単一ラベル形式へ置き換える

Status: ACTIVE
Supersedes: ADR-016
Reason: WindowsのmDNS解決に3ラベル以上の名前を使えないため、アプリ、Dashboard、APIの公開名をハイフン連結した単一ラベルへ変更する。Avahiを使った`.local` mDNS提供方式は維持する。
NewBaseline: ADR-018, CHG-096
CurrentValue: current
ValidityScope: LWSの公開ホスト名とmDNS
ReactivatedIf: Windowsを含む対象mDNS resolverで従来のドット区切り名が3ラベル以上でも解決できることを確認し、利用要件も再評価した場合のみ再検討する。
Related: ADR-016, ADR-018, CHG-096
