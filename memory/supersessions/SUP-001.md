# SUP-001: Robotの内部テスト代理実行を通常参照から外す

Status: ACTIVE
Supersedes: CHG-052
Reason: Robotから既存のGo・Shellテストを再実行してGREENにする方式は、受け入れテストと内部テストの責務を混在させ、品質ゲート統合後のQA契約に適合しないため。
NewBaseline: ADR-010, CHG-053
CurrentValue: current
ValidityScope: Robot Frameworkの受け入れテスト
ReactivatedIf: 実環境の利用者境界を検証するRobotシナリオとして再実装する場合のみ、CHG-052を移行履歴として確認する。
Related: ADR-009, CHG-052, CHG-053
