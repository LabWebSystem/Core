# ADR-012: DashboardをReact・Chakra UIの同一画面管理クライアントとして実装する

Status: ACCEPTED
Context: LWSのBackendはOpenAPIを正本としてアプリ管理APIとSSEを提供するが、Dashboardはモックコンテナだけで、非専門家が操作できる管理画面がなかった。
Decision: DashboardはReact、Vite、TypeScript、Chakra UI、TanStack Queryで実装する。OpenAPIからTypeScript型を生成し、アプリ一覧・詳細・操作・設定・ログを3ペインの同一画面で扱う。Dashboardは`dashboard.<base-domain>`で公開し、同一Originの`/api/v1`をCaddy経由でBackendへ中継する。BackendはDashboard Originだけを受理する。
Rejected: LWS本体操作をDashboardへ追加すること。Backend APIの型をDashboardへ重複定義すること。Material Designを既定とする包括的UIライブラリを採用すること。複数画面とカード中心の構成を初期実装すること。
Consequence: DashboardのAPI変更はOpenAPI型生成とDashboardテストを更新する。公開ドメイン、Caddy、Backend Origin境界は一つの変更として検証する。Chakra UIの標準アニメーションだけを初期採用し、複雑な独自アニメーションは必要になるまで導入しない。
Related: ADR-002, ADR-003, ADR-004, ADR-010, ADR-011, CHG-064
CurrentValue: current
FutureRelevance: reusable
ValidityScope: LWS Dashboard、API client、Dashboard公開経路
