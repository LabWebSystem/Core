# ADR-008: Infrastructure・Backend開発フェーズの現状

Status: ACCEPTED
Context: InfrastructureとBackendの実装をフェーズ単位で進めており、完了済みの範囲、現在の受け入れ基準、次に実装すべき範囲を一つの判断基準として残す必要がある。
Decision: フェーズ0〜5の実装を完了とする。SQLiteを正本としたDNS・Reverse Proxy反映、app単位のedge network再調整、登録解除・再登録・purge、所有resource限定削除、原子性と失敗時復元、Operation状態SSE、コンテナログ収集、低速購読者の隔離、Backend再起動時の未完了Operation整理まで実装済みである。残る課題は、v1の利用者視点受け入れテストと実環境シナリオの拡充である。
Rejected: フェーズ5の管理API clientをInfrastructureまたはBackendへ先行実装すること。Dashboardまたは将来の外部利用者がBackend API clientの責務を持つ。Docker操作方式をDocker Engine Go SDKへ変更すること。現行方針はDocker CLIである。
Consequence: 以後の仕様変更でも、登録解除後のsource・runtime・設定・named volume・DB記録の保持、所有確認済みresourceだけのpurge、SSE切断・欠損時のHTTP再取得を維持する。内部テストの成功だけで、未実装の利用者視点受け入れテストを完了扱いにしない。
