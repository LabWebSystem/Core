# ADR-001: LWS配布とライフサイクルの基盤

Status: ACCEPTED
Context: コンポーネントがモック段階でも、再現可能なインストールとリリースの経路が必要です。
Decision: ローカルタスクの入口は`mise`とし、LWSの`.deb`/`.rpm`成果物はGitHub Releases、モックイメージはGHCRのWorkflow、SDKはGitHub Packagesで独立して公開します。実行時ライフサイクルは6コマンドの`lwsctl`に集約し、安全な停止・再構成のためComposeプロジェクトとLWS所有ラベルを使用します。
Rejected: パッケージインストール時のコンテナ起動、パッケージへのイメージ同梱、`lwsctl`によるAPT/DNF管理ファイルの置き換え。
Consequence: `start`が初回設定を行い、`down`がLWS実行環境を撤去する。パッケージ削除hookはComposeプロジェクトを撤去し、`down --purge`だけが破壊的なデータ削除を行います。パッケージ削除はAPT/DNFへ委譲する。`update`は更新前の稼働状態を維持し、停止中のLWSを起動しない。
Related: docs/LabWebSystem設計概要.md
CurrentValue: current
ValidityScope: LWS基盤の配布とライフサイクル
